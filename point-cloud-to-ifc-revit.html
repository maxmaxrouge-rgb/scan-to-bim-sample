Scan-to-BIM sample / Conversion guide

How to get a point cloud converted to an IFC or Revit model

Inferred buyer query: “point cloud to IFC conversion service”. This guide targets a scoped sample request. Search volume and buyer demand are unverified.

Inferred approach: start with one bounded area, agree the output, then review a sample before commissioning wider modelling.

1. Prepare the conversion brief

Inferred checklist for a quote request:

  • State the building type, approximate floor area and the area required for the sample.
  • Name the scan format, units, coordinate system and whether registration has been checked. Mark missing information as unknown.
  • Describe the intended use and which elements need modelling. State any required checks and acceptance criteria.
  • Specify IFC output or a native Revit deliverable. For Revit, name the required version and editing requirements.
  • State the deadline and any access restrictions. Agree a private transfer method before sharing scans.

2. Use the live IFC sample to discuss scope

The proposed scope covers one supplied indoor scan and up to 15 fitted plane elements, with IFC export and a limitations report. This price is a proposal, not a quote.

Prior (published sample record): the illustrative model contains 7 wall elements and 5 slab elements from one scan. No independent survey comparison occurred.

Inferred review method: open the IFC browser viewer, compare the visible elements with the QA report, and download sample.ifc for a proposed receiving workflow. Record which required elements are absent or uncertain.

unknown: occlusion or opening not independently supported

Prior (published QA record): element classifications, extents and 0.1 m thickness are illustrative or inferred. Plane-fit residuals do not establish surveyed accuracy. This sample is not suitable for construction or survey decisions.

3. Agree IFC and Revit deliverables separately

Verified (fetched https://maxmaxrouge-rgb.github.io/scan-to-bim-sample/point-cloud-to-ifc-revit.html): the current public offer names IFC export. It does not promise a native Revit file.

Inferred scope checklist: if the destination is Revit, specify whether an IFC handover meets the intended use. If editable native elements are required, request explicit confirmation of that deliverable, version, exclusions and price before work starts. This guide makes no Revit compatibility or conversion-result claim.

4. Define the sample review

Inferred acceptance checklist: agree the modelled area, element types, units, coordinates and receiving application. Define how unsupported geometry and missing evidence appear in the report. Keep independent accuracy checks separate from visual review.

Inferred next step: compare the sample against those agreed checks before expanding the scope. A browser preview alone does not establish project suitability.
